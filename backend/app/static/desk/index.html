Triage citizen reports.
Evidence first, owner data second.

Each report shows the photo, the plate the system read, the plate the citizen typed, and a registry match with reasons. A match is a lead to verify, never a conclusion.

Officer sign-in

Demo build: access is one shared key. Set it with the EXLEX_OFFICER_KEY environment variable before starting the server; if it is not set, a random key is printed once in the server log. A real deployment would use individual officer accounts.
